# Алаш дәуірі — интерактивный учебный сайт

Тема: «Қазақстанның ХХ ғасыр басындағы саяси-экономикалық және әлеуметтік жағдайы (Алаш қозғалысы, Петициялар, I және II Орыс Думалары, Қазақ зиялылары)».

## Состав

```
alash-site/
├── index.html         — страница сайта
├── assets/style.css   — оформление (в т.ч. мобильная версия)
├── assets/app.js      — весь контент и логика
├── assets/hero.jpg    — главная картинка
└── README.md
```

Разделы: Басты бет · Карта · Видео · Оқу (10 тезис) · Тұлғалар (10) · Оқиғалар · Деректер (30 факт) · Ойын (5 тапсырма) · Сауалнама (10 сұрақ) · Терминдер · Нәтиже.

## Как открыть

- **Локально:** распакуйте архив и откройте `index.html` в браузере (Chrome, Edge, Safari, Firefox). Для красивых шрифтов нужен интернет; без него сайт работает на системных шрифтах.
- **В интернете (бесплатно):** загрузите папку `alash-site` на GitHub Pages, Netlify Drop (app.netlify.com/drop) или Vercel. Сервер не нужен — сайт полностью статический.

## Как изменить контент

Все тексты лежат в начале `assets/app.js` в массивах:

- `THESES` — тезисы
- `FACTS` — факты
- `PEOPLE` — тұлғалар
- `EVENTS` — оқиғалар
- `TERMS` — терминдер
- `TEST`, `ORDER`, `MATCH`, `MAPQ`, `TF` — задания

Карта — схема: внешний контур взят из открытых данных Natural Earth, внутренние границы облыстар около 1900 года приблизительные.
